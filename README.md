# Fun Event Website

A luxury, responsive single-page website for **Fun Event**, a UAE-based events company established in 2011. The experience presents the company, its services, selected event imagery, and its background through a cinematic "Midnight Majlis" visual direction.

## Highlights

- Cinematic autoplay hero video with a static poster fallback
- Responsive desktop, tablet, and mobile layouts
- Obsidian, bronze, and warm-gold luxury visual system
- Scroll reveal, progress, and parallax effects
- Accessible navigation and reduced-motion support
- Optimized WebP imagery and compressed MP4 video
- No framework or build process required

## Local preview

From the repository root, run:

```bash
python3 -m http.server 8080 --directory dist
```

Then open `http://localhost:8080` in a browser.
